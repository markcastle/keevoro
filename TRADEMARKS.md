# The Keevoro name and logo

The code in this repository is covered by its licence, [LICENSE.md](LICENSE.md). The name and the logo are not.

"Keevoro", the Keevoro logo and the Keevoro lockup (the files in `design/` and `ui/src/assets/` that carry them, and the app icons made from them) belong to Mark Castle. The licence gives no right to use them, as its Trademarks section says.

## What that means in practice

You are welcome to:

- say that your work is built on, or works with, Keevoro;
- use the name to refer to this project, in writing, talks and reviews;
- build and run Keevoro from this source for yourself, logo and all.

Please do not:

- give out a changed version under the Keevoro name or logo. If you share a fork, call it something else and use your own icon, so nobody mistakes it for this project;
- use the name or logo in a way that suggests this project made, checked or stands behind something it did not.

If you are unsure whether a use is fine, open an issue and ask.
